╔══════════════════════════════════════════════════════════╗
║  📝 КАК ДОБАВИТЬ СВОЙ ДОМЕН ДЛЯ БЛОКИРОВКИ              ║
╚══════════════════════════════════════════════════════════╝

ЧЕРЕЗ ПОПАП (просто):
1. Нажать на иконку расширения
2. Ввести домен (например: doubleclick.net)
3. Нажать "+"

ЧЕРЕЗ rules.json (навсегда):
1. Открыть rules.json
2. Добавить новый объект в массив:
   {
     "id": 6,
     "priority": 1,
     "action": { "type": "block" },
     "condition": {
       "urlFilter": "||новый-домен.ru^",
       "resourceTypes": ["script", "image", "xmlhttprequest", "sub_frame"]
     }
   }
3. Перезагрузить расширение в chrome://extensions/

╔══════════════════════════════════════════════════════════╗
║  🔍 КАК НАЙТИ РЕКЛАМНЫЙ ДОМЕН                            ║
╚══════════════════════════════════════════════════════════╝
1. Зайти на сайт с рекламой
2. F12 (открыть инструменты разработчика)
3. Вкладка "Сеть" (Network)
4. Обновить страницу (F5)
5. Искать подозрительные названия: ad, banner, doubleclick и т.д.
6. Скопировать домен и добавить в rules.json

Расширение удаляет все iframe, включая:
- Видео с YouTube
- Плееры VK
- Посты с Instagram/Twitter
- Карты (Яндекс.Карты, Google Maps)
- Виджеты комментариев

ТРЕБУЕТ ИСПРАВЛЕНИЯ:
- Селектор 'iframe:empty' в content.js
- Нужно уточнять, какие именно iframe являются рекламой
- Добавить проверку src атрибута
